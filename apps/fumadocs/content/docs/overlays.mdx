title: Overlays
description: How to add DireWork overlays to OBS
---

DireWork provides two overlays that you add as browser sources in OBS (or any streaming software that supports them).

## Overlay URLs

After signing in, go to your **Dashboard**. Each console has its overlay URL in the strip along its bottom edge:

- **Timer overlay** — `/overlay/t/{token}`, under the Pomodoro console
- **Tasks overlay** — `/overlay/l/{token}`, under the task board

Each overlay has its own private URL. The row is masked by default: use the Show button to reveal it, or the Copy button to copy the full URL.

<Callout type="warn">
  Keep your overlay tokens private. Anyone with the URL can view your overlay. If a token leaks, use the Reset button next to the URL to issue a new one.
</Callout>

## Adding to OBS

1. In OBS, click the **+** button under Sources
2. Select **Browser**
3. Name it (e.g. "DireWork Timer" or "DireWork Tasks")
4. Paste the full overlay URL (e.g. `http://localhost:3001/overlay/t/YOUR_TOKEN`)
5. Set the dimensions:
   - **Timer:** 300 x 300 (the timer scales to fill the browser source, so any size works)
   - **Task List:** 700 x 800
6. Check **"Shutdown source when not visible"** (recommended — the source reloads cleanly when you switch scenes)
7. Click **OK**

## Timer overlay

The timer overlay shows:
- Current phase label (defaults are wolf-themed and editable in Theme Center — e.g. "Gathering the Pack", "On the Hunt", "Den Rest", "Pack Slumber", "Paws'd", "Hunt Complete")
- Countdown timer with configurable font
- Cycle count (e.g. 1/4)
- Progress ring (circle or rounded rectangle shape)

While the timer is idle, the overlay shows a full preview — the configured work length plus a full progress ring — rather than appearing blank, so you can position it during setup.

The timer automatically transitions through phases: Starting (5s countdown) → Focus → Break → Focus → … with a Long Break replacing the regular Break every few cycles (4 by default), ending in Done after the final Focus. The timer moves forward whenever something is watching it: an open timer overlay in OBS checks in every few seconds and advances the timer on its own — no dashboard tab needs to stay open. The dashboard or an incoming chat command will nudge it forward too.

### Progress ring shapes

The timer supports two progress ring shapes:

- **Circle** — Standard circular ring using SVG `<circle>`
- **Rounded Rectangle (Squircle)** — macOS-style rounded corners, drawn as an SVG `<path>`. The corner radius comes from the **Background border radius** setting (default 22%), which is shared with the container — there is no separate ring radius. Set that value to `50%` to switch the ring to a full circle instead.

## Task list overlay

The task list overlay shows:
- Header with "Tasks" title and completion count
- Tasks grouped by author — each author gets a styled card with a tinted header row showing their name and done/total count
- Individual tasks render inside their author's group container
- Checkboxes (or bullets) for task status
- Completed tasks with strikethrough text

The task a viewer is working on right now gets a soft tint in the username color and an **Active** label at the end of the row. Nothing pulses or glows.

When scroll is enabled, the task list loops in a smooth, continuous scroll so every task gets screen time. You can turn scroll off in the Theme Center to show a fixed list instead; when the list is longer than the overlay, a "+N more" line at the bottom says how many tasks are cut off.

## Dashboard preview

The dashboard shows a live preview of each overlay under its URL, beside the timer controls and the task board. Use **Live preview** to turn a preview on or off. Previews are off by default: a preview polls the API like a real overlay for as long as it is shown.

## Customization with Theme Center

Both overlays are fully customizable through the **Theme Center** at `/dashboard/styles`. This is a visual editor with a live preview panel.

The preview sits beside the editor (below it on a phone) and shows one overlay at a time:
pick **Timer** or **Tasks**, then a backdrop — dark, light, bright (a sunny camera feed, the
hardest case for light text) or a checkerboard that shows what is transparent. The task list
is drawn at the recommended 700 × 800 source size and scaled down, so its proportions match
OBS. The sample tasks and countdown are the same demo session the docs and landing page use.

Edits stay in the preview until you save. The chip above the preview reads **Previewing
unsaved changes** while they differ from what is live, and **Matches the saved theme** once
they don't; the save bar at the bottom says the change is **not on stream yet**. **Save
changes** updates both OBS overlays in one step; **Reset** discards every edit since the last
save.

The presets sit in a gallery at the top (arrow keys move between them; Enter or Space applies
one). Below it, the editor has three tabs — **Timer style**, **Task style** and **Phase
labels** — and a dot on a tab means it holds unsaved edits. Each style tab is split into four
sections: **Colors** (open first), **Typography**, **Layout** and **Opacity**. Inside a
section, settings are grouped by the part of the overlay they change (the panel, the progress
ring, the header, task rows…).

Two resets put values back to the **Default** theme without saving: a section's **⋯** menu →
**Reset section** resets just that section of that overlay, and the **⋯** menu beside the
page title → **Reset theme to Default** resets both overlays' styles (phase labels stay).
Both ask first, and neither reaches your stream until you press **Save changes**.

### Timer overlay settings

| Section | Options |
| --- | --- |
| **Colors** | Panel background; progress ring fill and track; text color and outline color |
| **Typography** | Font family, outline size; phase label, countdown and pomo counter sizes |
| **Layout** | Width, height, corner radius; show ring, ring width, ring gap |
| **Opacity** | Panel background; ring fill and track |

The **Phase labels** tab sets the text for each of the seven phases — Idle, Starting, Focus,
Break, Long break, Paused, Done. Defaults are wolf-themed: "Resting", "Gathering the Pack",
"On the Hunt", "Den Rest", "Pack Slumber", "Paws'd", "Hunt Complete".

> The progress ring has no dedicated shape control — its shape follows the panel's
> **Corner radius** (Layout). Set the border radius to `50%` for a circle; any other value (e.g. `22%`)
> renders a rounded rectangle (squircle).

> The default countdown is 76px, sized for `25:00` in a 300×300 timer. With **Show hours**
> on, hours shrink the digits automatically: the longer `01:25:00` is drawn no wider than
> `25:00` would be, so it still fits inside the ring.

### Task list overlay settings

| Section | Options |
| --- | --- |
| **Colors** | Background, text and border colors for the header, body and task rows; fallback username color (used when a viewer has no Twitch chat color); done-task background and text; checkbox background, border and tick; bullet color |
| **Typography** | Header and body fonts; header and task font sizes; tick character and size; bullet character and size |
| **Layout** | Show done tasks, show count, checkboxes, cross out done tasks, lines per task; scroll on/off, speed and loop gap; heights, padding, margins, border widths, corner radii and max width |
| **Opacity** | Background opacity of the header, body, task rows, done tasks and checkboxes |

Bullet settings appear only while **Checkboxes** is off.

### Theme presets

The Theme Center includes 6 built-in presets to get you started. All of them share the same
proportions: a thick progress ring, a large countdown, large task text, and no outlines around
the panels.

1. **Default** — Midnight blue with a cyan ring. A fresh install starts on this preset.
2. **Ocean Depths** — Deep navy with a teal ring and teal names
3. **Liquid Glass Dark** — Translucent graphite panels with a blue ring
4. **Cozy Cottage** — Soft cream panels with brown text and a gold ring
5. **Minimal Light** — Plain white with an indigo ring and thin grey edges
6. **Twitch Purple** — Near-black panels with a Twitch purple ring and lavender names

Apply a preset as a starting point, then customize individual settings to match your stream.

If you never changed a style, your overlays pick up new default styles when DireWork updates
them. Any group of settings you changed (for example the ring, or the task header) stays exactly
as you saved it.

## Transparent background

The overlays render with a transparent background by default. In OBS, the browser source will show only the timer or task list widget without any background, making it easy to layer over your stream.

## How updates work

Both overlays check for changes every **few seconds**. When you start the timer,
add a task, or make any change on the dashboard, the overlay picks it up within a few
seconds.

The timer countdown itself doesn't wait for those checks — it ticks down smoothly on the
overlay, computed from the timer's end time. Your viewers never see a stuttering clock.
