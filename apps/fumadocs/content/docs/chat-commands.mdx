Once you've connected a [bot account](/docs/twitch-oauth#step-5-connect-the-bot-account), viewers can interact with DireWork through Twitch chat commands.

<Callout type="info" title="New to the stream? (for viewers)">
  1. Type `!task` and what you're working on, like `!task read 10 pages`.
  2. Work along with the stream.
  3. Type `!done` when you finish.

  Stuck on a command? Type `!dw help` and its name, like `!dw help done`.
</Callout>

<Callout>
  **The bot listens while its page is open.** Copy the bot page URL from
  **Dashboard → Bot** and add it to OBS as a browser source (or keep it in a pinned
  browser tab). While that page is open, the bot reads chat and replies — close it and
  the bot goes quiet. If you regenerate the bot token, re-copy the URL.
</Callout>

## Task commands (all viewers)

| Command | Description |
| --- | --- |
| `!task <text>` | Add a new task (your first task automatically becomes your active one) |
| `!done` | Mark your active task as done |
| `!done <number>` | Mark a specific task by position as done (`!done 2` and `!done #2` both work; anything that isn't a number gets a usage hint instead of completing your active task) |
| `!edit <number> <text>` | Edit a specific task by position |
| `!remove <number>` | Remove a specific task by position |
| `!focus <number>` | Set a task as your active/focused task |
| `!check` | Show your current active task |
| `!check @user` | Show another user's active task (the `@` is optional, and trailing punctuation like `@user?` is ignored) |
| `!today` | Show your active task, next two tasks (with their numbers), and how many more are queued |
| `!next <text>` | Complete your active task and start a new one |
| `!help` | Post the 3-step starter guide (the streamer can reword it) |

## Task commands (broadcaster / mods)

| Command | Description |
| --- | --- |
| `!clear all` | Clear all tasks from the list |
| `!clear done` | Clear all completed tasks |
| `!clear @user` | Remove all tasks from a specific user (the bot says so when that user had none) |

## Timer commands (broadcaster / mods)

| Command | Description |
| --- | --- |
| `!timer start` | Start the timer with default settings |
| `!timer start <cycles>` | Start the timer with a specific cycle count |
| `!timer pause` | Pause the timer |
| `!timer resume` | Resume the timer |
| `!timer skip` | Skip the current phase |
| `!timer reset` | Reset the timer to idle |
| `!timer eta` | Show time remaining in the current phase and the whole session (while paused, the frozen time left) |

Task numbers are the ones `!today` shows, so `!edit #2 …`, `!remove #2` and `!focus #2` work as well as the plain number.

When `!timer pause`, `resume` or `skip` can't do anything, the bot says why instead of
replying "Done.": pausing a paused timer gets `The timer is already paused. Use !timer resume
to continue.`, resuming a running one gets your **Timer Running** reply, and if another
action changed the timer at the same moment it replies `The timer changed just before that,
so I left it alone. Check it and try again.` These fixed replies aren't editable.

## Moderation commands (broadcaster / mods)

| Command | Description |
| --- | --- |
| `!mute` | Pause the bot: it ignores every command and posts nothing |
| `!unmute` | Resume the bot |
| `!block @user` | Block a viewer and remove every task they added |
| `!unblock @user` | Let a blocked viewer use commands again |

- **Muted means everything.** While muted the bot ignores every command, task, timer and
  meta commands included, and posts nothing in chat. The only command that works is a
  mod's `!unmute`. The board and timer stay as they are. You can also flip the **Mute bot**
  switch at the top of **Dashboard → Bot**.
- **Blocked viewers get no reply.** The bot silently ignores their commands, and blocking
  removes every task they added. `!unblock` restores their commands, not their tasks.
- **The streamer can't be blocked**, and the streamer's own commands always run.
- **Blocking is by Twitch login.** A viewer who renames their account slips the block;
  block the new name too. The block list holds up to 200 names and is also editable under
  **Moderation** on **Dashboard → Bot**.

## Meta commands (always available)

These commands are always enabled regardless of task or timer command settings (but, like
everything else, they stay silent while the bot is muted).

| Command | Description |
| --- | --- |
| `!dw` or `!dw help` | Posts the built-in 3-step starter guide. It can't be reworded, so it still works if the streamer customized `!help`. If task commands are off, it says so instead |
| `!dw help <command>` | Explains one command in plain words with an example, like `!dw help task`. Takes `task`, `!task`, any capitalization, or one of the streamer's aliases; mod-only commands are marked "(mods only)". `!dw task` works too |
| `!dw commands` | Same as `!dwhelp` |
| `!dwhelp` | Posts a link to this commands reference page — or, if no docs URL is configured, an inline list of the available commands |
| `!dwcommands` | Same as `!dwhelp` |

## Active task and focus

When you add your first task with `!task`, it automatically becomes your **active** task. Subsequent tasks are added as **pending**.

- Your active task is what shows as your current focus in the overlay and in `!check` responses.
- When you complete a task with `!done`, the next pending task is automatically activated.
- Use `!focus <number>` to manually switch which task is active. The number is the position in your task list (1-based).

## Today's plan

`!today` shows your active task first, followed by the next two tasks in your list, each with its number (`Now: #2 … · Next: #1 …`). Those are the numbers `!done`, `!edit`, `!remove` and `!focus` take. If you have more open tasks, it shows how many remain. It only shows your own tasks; it does not assign due dates or expose another viewer's list.

## Command aliases

Broadcasters can remap command names in **Bot Settings** (`/dashboard/bot`). For example, you could set `add` to map to `task`, so viewers can use `!add` instead of `!task`.

An alias can point at any task or timer command (`task`, `done`, `edit`, `remove`, `focus`, `check`, `today`, `next`, `help`, `clear`, `timer`) — not the meta or moderation commands (`!dw`, `!dwhelp`, `!dwcommands`, `!mute`, `!unmute`, `!block`, `!unblock`). Each alias and target is a single command name with no arguments, so `!ts` → `!timer start` is not supported. Aliases can't reuse a built-in command name, so the built-in commands always keep working regardless of your aliases.

To save requests on Cloudflare's free plan, the bot page only forwards chat lines that start with a DireWork command or one of your aliases; other bots' commands (`!lurk`, `!so`) never leave the page. An open bot page picks up **new aliases** within an hour; reload the bot page (or refresh the OBS browser source) to use them right away.

## Task priority

Tasks created by the broadcaster (stream owner) are pinned to the top of the list. Viewer tasks appear below in the order they were added.

## Bot responses

All bot response messages are customizable from the **Bot Settings** page (`/dashboard/bot`). Task and timer command groups can also be individually enabled or disabled.

### Task bot responses

| Message | Default | Variables |
| --- | --- | --- |
| Task Added | `Added "{task}" to the pack, {user}.` | `{task}`, `{user}` |
| No Task Added | `Your paws are full, {user}. Finish one with !done before adding another.` | `{user}` |
| No Task Content | `Tell the pack what you're working on, {user}: !task [task]` | `{user}` |
| No Task to Edit | `Nothing to edit there, {user}. Try !edit [number] [new task].` | `{user}` |
| Task Edited | `Updated your task to "{task}", {user}.` | `{task}`, `{user}` |
| Task Removed | `Removed "{task}" from the list, {user}.` | `{task}`, `{user}` |
| Task Next | `Finished "{oldTask}". Now on "{newTask}", {user}.` | `{oldTask}`, `{newTask}`, `{user}` |
| Admin Delete Tasks | `Cleared that viewer's tasks.` | none |
| Task Done | `Nice work, {user}. "{task}" is done.` | `{task}`, `{user}` |
| Task Check | `{user}, you're on "{task}".` | `{user}`, `{task}` |
| Task Check User | `{user}, {user2} is on "{task}".` | `{user}`, `{user2}`, `{task}` |
| No Task | `You don't have a task yet, {user}. Start one with !task [task].` | `{user}` |
| No Task (Other) | `{user}, that viewer doesn't have a task right now.` | `{user}` |
| Not Mod | `Sorry {user}, only mods can do that.` | `{user}` |
| Cleared All | `Cleared every task.` | none |
| Cleared Done | `Cleared the finished tasks.` | none |
| Next No Content | `What's next, {user}? Try !next [task].` | `{user}` |
| Viewer starter guide (`!help`) | `{user}, here's how it works: 1) Type !task and what you're working on, like !task read 10 pages. 2) Work along with the stream. 3) Type !done when you finish. Need more? Type !dw help` | `{user}` |

If you never edited a reply, your bot picks up new default wording automatically when you update DireWork. Replies you customized are never touched; use **Reset to default** on the Bot settings page to get the stock wording back.

### Timer bot responses

| Message | Default | Variables |
| --- | --- | --- |
| Not Running | `The timer isn't running. Start it first.` | none |
| Wrong Command | `Didn't catch that. Try !timer start, pause, resume, skip, reset, or eta.` | none |
| Timer Running | `The timer is already running.` | none |
| Command Success | `Done.` | none |
| Cycle Wrong | `Pick a cycle count from 1 to 99, like !timer start 4.` | none |
| ETA | `This phase ends in {phase} · the session ends in {time}` | `{phase}`, `{time}` |

<Callout type="info">
  The bot replies to `!timer` commands, but does not announce phase changes on
  its own. DireWork runs on Cloudflare Workers with no always-on process, so
  there is nothing to fire a message when a focus block ends — the overlay is
  what shows the current phase. Editable "focus started" / "break started" /
  "stream starting" / "timer finished" messages used to exist here but never
  sent anything, so they were removed.
</Callout>

### Message variables reference

| Variable | Description |
| --- | --- |
| `{user}` | The Twitch display name of the person who ran the command |
| `{user2}` | The Twitch display name of the target user (e.g., `!check @other`) |
| `{task}` | The task text content |
| `{oldTask}` | The task that was just completed (used in `!next`) |
| `{newTask}` | The new task now being tracked (used in `!next`) |
| `{channel}` | The Twitch channel name, used as @mention to ping chat |
| `{phase}` | Time remaining in the current phase, as a relative duration (e.g., `18m`) |
| `{time}` | Time remaining until the whole session ends, as a relative duration (e.g., `1h 55m`) |
