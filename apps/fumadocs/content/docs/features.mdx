DireWork is a self-hosted Pomodoro timer and task list built specifically for Twitch co-working and body-doubling streams. Here's everything it includes.

## Pomodoro timer

A Pomodoro timer with automatic phase transitions.

- **Configurable durations** — Set Focus, Break, and Long break durations (in minutes) from the dashboard
- **Long break intervals** — Automatically triggers a long break every N cycles (configurable)
- **Cycle tracking** — Set the number of pomos per session (1-99)
- **Automatic phase transitions** — The timer moves through Starting, Focus, Break, and Long break on its own, ending in Done
- **Pause and resume** — Pause mid-session and resume exactly where you left off (remembers which phase you were in)
- **Skip phase** — Skip the current phase to advance to the next one
- **5-second starting countdown** — Brief countdown before work begins so you can get ready
- **Real-time OBS overlay** — Circular or rounded-rectangle progress ring with countdown, phase label, and cycle count

## Task list

A task list your viewers manage from Twitch chat.

- **Chat commands** — Viewers add, edit, complete, and remove tasks with commands like `!task`, `!done`, `!edit`, `!remove`
- **Multiple tasks per viewer** — Each viewer can have multiple tasks, numbered for easy reference
- **Focus and started tasks** — Each viewer has one focus task and can keep up to two more started beside it (`!start` / `!pause`); the overlay marks the focus **Active** and the others **Started**
- **Task priority** — Broadcaster tasks are pinned to the top, viewer tasks below in order
- **Broadcaster controls** — Clear all tasks, clear completed tasks, or remove a specific user's tasks
- **Author grouping** — Tasks are grouped by author, each with a styled card container showing the author's name and done/total count
- **Real-time OBS overlay** — Task list with usernames in Twitch chat colors, checkboxes, and strikethrough for completed tasks
- **Auto-scroll** — Toggleable infinite scroll animation when the list overflows the display area

## Theme Center

A visual editor for customizing your overlays, available at `/dashboard/styles`.

- **6 built-in theme presets** — Default, Ocean Depths, Liquid Glass Dark, Cozy Cottage, Minimal Light, Twitch Purple
- **Preset gallery** — Every preset at a glance, applied with one click (keyboard: arrows, then Enter)
- **Timer, task and phase-label tabs** — A dot marks any tab with unsaved edits. Each style tab is split into Colors, Typography, Layout and Opacity, grouped by the part of the overlay they change
- **Resets that never surprise you** — Reset one section, or the whole theme, to Default; both ask first and only change your draft until you save
- **Live preview** — See every edit before it reaches OBS: switch the preview between the timer and the task list, play the countdown, and judge it over a dark, light, bright (sunny camera feed) or checkerboard backdrop. A chip says whether you are previewing unsaved changes or the saved theme, and nothing reaches the stream until you press **Save changes**, which updates both overlays at once
- **Progress ring shapes** — The ring follows the background's border radius: `50%` draws a circle, any other radius draws a rounded rectangle (squircle)
- **Per-property control** — Every color, size, opacity, font, and spacing value is individually configurable

## Twitch chat bot

Connect a separate Twitch bot account to handle chat commands.

  <Image src={botScreenshot} alt="The WolfBot dock, connected to the wolfstreamer channel, with a MoonWolf task command and its reply" unoptimized />
  <figcaption>WolfBot demo with a simulated Twitch connection. This is not a live stream.</figcaption>
</figure>

- **Task commands** — `!task`, `!done`, `!edit`, `!remove`, `!focus`, `!start`, `!pause`, `!check`, `!today`, `!next`, `!help` for all viewers
- **Timer commands** — `!timer start`, `!timer pause`, `!timer resume`, `!timer skip`, `!timer reset`, `!timer eta` (mods only)
- **Moderator commands** — `!clear all`, `!clear done`, `!clear @user` (mods only) to clear all tasks, only completed tasks, or one viewer's tasks; `!mute` / `!unmute` to pause the bot and `!block @user` / `!unblock @user` to manage the block list
- **Mute switch** — Pause the bot from **Dashboard → Bot** (or with `!mute`): it ignores every command and posts nothing until it's unmuted
- **Blocked viewers** — Ignore a viewer's commands and remove their tasks; manage the list from chat or the dashboard's **Moderation** card
- **Customizable bot messages** — Configure response templates for every command
- **Command aliases** — Create custom aliases for any command
- **Separate bot account** — Uses its own Twitch account so messages come from the bot, not you
- **Runs in your browser** — The bot lives in a private browser page: an invisible widget you add to OBS or Moblin, or a dock with controls in OBS or a pinned tab; no always-on bot server to run

## OBS overlays

Two transparent browser source overlays designed for OBS and streaming software.

- **Timer overlay** — Shows phase label, countdown, and cycle count with a configurable progress ring
- **Auto-scaling timer** — The timer overlay auto-scales to fill its OBS browser source while preserving aspect ratio, and while idle it shows a full preview (your configured work length and a full ring) instead of appearing blank, so you can position it during setup
- **Task list overlay** — Shows task list with viewer usernames, checkboxes, and auto-scroll. Each viewer's focus task comes first, tinted and marked **Active**; tasks they started beside it (up to two, via `!start`) follow with a small **Started** label and no tint
- **Transparent backgrounds** — Overlays render with no background, layering cleanly over your stream
- **Private overlay URLs** — Each overlay has its own private overlay URL; reset it if it ever leaks
- **Fast updates** — Overlays pick up changes within a few seconds, and the timer countdown ticks smoothly on the overlay itself
- **Toggle previews** — Dashboard previews are off until you turn them on, so the dashboard only polls for them while they are shown

## Dashboard

A single-page control center for your stream.

<figure>
  <Image src={dashboardScreenshot} alt="Wolf Streamer's dashboard showing the timer and three example tasks with private URLs masked" unoptimized />
  <figcaption>Real local dashboard with fictional Wolf Streamer data and masked private URLs.</figcaption>
</figure>

- **Set up streaming checklist** — Four steps from a fresh install to a working stream: connect the bot account, then add the bot (as an invisible widget or a dock, your pick), the timer overlay and the tasks overlay to OBS. Each OBS step shows its URL and an **I added it to OBS** button. DireWork can't see inside OBS, so those steps count once you confirm them (and **Mark as not added** undoes it). **Finish later** hides the card; the **Setup** button next to the greeting brings it back
- **Stream stats** — Under the greeting: focus time, pomodoros and tasks done today (with how many came from chat), and how many days you streamed this week plus your week streak (consecutive weeks with at least one focus day). Under the timer, a 14-day chart of focus minutes with today highlighted. A pomodoro counts when a work phase runs to its end, even with no page open; skipping or stopping a work phase still counts the minutes you worked (paused time never counts). Days follow your browser's time zone, which the dashboard saves the first time it loads. Stats are kept for about 400 days and cost no extra polling
- **Timer controls** — Start, pause, resume, skip, and stop the timer with inline duration settings and info tooltips
- **Task manager** — Add, complete, focus, and remove tasks (with Undo) directly from the dashboard
- **Overlay previews** — Live iframe previews of both overlays (toggleable)
- **Overlay URLs** — Copy each overlay URL for OBS with one click, or reset it if it leaks. Both live in the dashboard's **OBS sources** (a Timer and a Tasks tab), each with its recommended OBS browser-source size: 300×300 for the timer and 700×800 for the task list
- **Bot management** — Connect, view status, and disconnect your bot account
- **Time-of-day greeting** — The dashboard greets you by name, early morning, morning, afternoon, evening or late night, with a different line (often a wolf pun) each day

## UI and design

- **Focus Console design** — a dark-first instrument-panel look: midnight-navy base, cerulean accent, and LED-style status chips
- **Cerulean accent** — a bright cyan-blue accent used sparingly on buttons, links, and active states
- **Dark and light mode** — Toggle between themes with a switch in the header
- **Responsive layout** — Works on desktop and mobile, with larger tap targets on touch screens and task actions that stay visible without a mouse
- **Install on your phone** — Add the dashboard to your home screen and it opens like an app, straight to the dashboard. In Chrome on Android, open the menu and choose **Install app**; in Safari on iOS, tap **Share** then **Add to Home Screen**. There is no offline mode: the dashboard shows your live timer and tasks, so it needs a connection
- **Glass-effect header** — Frosted glass navbar with backdrop blur and saturation

## Self-hosted and single-user

- **Single-user per instance** — Each streamer runs their own DireWork instance
- **Full data ownership** — Your data lives in your own Cloudflare account
- **Serverless database** — Cloudflare D1 (SQLite) — no database server to install or babysit
- **Free-tier support** — The core app requires no paid Cloudflare services and runs within the free plan's account quotas; no servers, no Docker. See [Free plan limits](/docs/deployment#free-plan-limits)
- **Static docs site** — Documentation builds as a static site, deployable separately

| **Docs** | Fumadocs with built-in static search |
| **Build** | Turborepo + Bun workspaces |
