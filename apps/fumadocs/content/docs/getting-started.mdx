This guide gets Dirework running on your own machine so you can try it before you
deploy it anywhere. Going to production instead? Jump to [Deployment](/docs/deployment).

<Callout>
  **No deep tech knowledge needed.** You'll copy a few commands, paste two Twitch keys,
  and you're done. Take it one step at a time — each step says exactly what to do.
</Callout>

## What you need first

Install these once. Click each name if you don't have it yet:

- [Bun](https://bun.sh) — the toolkit that runs everything (one install command on their site)
- [Docker](https://www.docker.com/products/docker-desktop/) — runs the database in the background
- A free [Twitch developer application](/docs/twitch-oauth) — this is where your two keys come from

That's the whole shopping list.

## 1. Get the code

```bash
git clone https://github.com/mrdemonwolf/dirework.git
cd dirework
```

## 2. Install + set up — one command

```bash
bun install
bun run setup
```

`bun run setup` does the boring parts for you: it creates your `.env` file, starts the
database in Docker, and loads the database tables. When it finishes, it tells you what to do next.

<Callout type="info">
  Seeing a Docker error? Make sure Docker Desktop is open and running, then run
  `bun run setup` again. It's safe to re-run.
</Callout>

## 3. Add your two Twitch keys

Open the new `.env` file in the project folder and fill in these two lines:

```bash
TWITCH_CLIENT_ID="paste_your_client_id"
TWITCH_CLIENT_SECRET="paste_your_client_secret"
```

Don't have these yet? The [Twitch OAuth Setup](/docs/twitch-oauth) page walks you
through getting them — it takes about two minutes. For local use, set your app's
redirect URL to:

```
http://localhost:3001/api/auth/callback/twitch
```

Everything else in `.env` already has a sensible default for local use. You don't need
to touch it.

## 4. Start it up

```bash
bun run dev:full
```

This starts the database (if it isn't already running) and launches both apps:

- **Your Dirework app** → [http://localhost:3001](http://localhost:3001)
- **This documentation** → [http://localhost:4000](http://localhost:4000)

✅ You should now see the Dirework welcome screen at `localhost:3001`.

## 5. Claim your instance

The first time you open the app, it sends you to a **setup screen**. Click
**Claim with Twitch** and sign in. That makes you the owner — one streamer, one instance.

✅ After signing in you land on your **dashboard**. You're in.

<Callout type="warn">
  The setup screen only appears once. After you claim the instance, it turns off for good.
</Callout>

## Handy commands

You'll mostly use `bun run dev:full`. These are here when you need them:

| Command | What it does |
| --- | --- |
| `bun run dev:full` | Start the database and both apps together |
| `bun run dev:web` | Start just the web app (database must already be running) |
| `bun run db` | Bring the database up, wait until it's ready, and sync the schema |
| `bun run db:start` | Start the database container on its own |
| `bun run db:stop` | Stop the database |
| `bun run db:studio` | Open a visual editor for the database |
| `bun run db:push` | Reload the database tables after a code update |
